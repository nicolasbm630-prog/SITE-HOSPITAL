# MedConnect — Estudo de caso UX/UI

Solução dos 7 desafios do caso MedConnect (Rede Vida+): problema e personas, jornada, user flow, heurísticas de Nielsen, acessibilidade WCAG, wireframes, protótipo navegável e kit de teste de usabilidade.

Site estático, sem build: basta abrir `index.html` no navegador.

- `index.html` — apresentação dos 7 desafios
- `prototipo/` — protótipo navegável de média fidelidade (as 12 telas pedidas e as telas de erro)
- `assets/` — estilos e scripts da apresentação

No protótipo, use qualquer CPF com 11 números e qualquer senha com 4 caracteres ou mais. O painel do apresentador (versão em tela cheia, desktop) simula erros e pode ser escondido com Shift + P antes do teste com usuários.

Estudo de caso acadêmico: a Rede Vida+, os pacientes, os médicos e os convênios são fictícios.
